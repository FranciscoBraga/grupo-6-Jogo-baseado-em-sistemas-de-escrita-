# Lendas da Escrita ⚔️

Jogo onde você escreve um texto e a IA gera seu herói com imagem personalizada!

## Como funciona

A IA lê seu texto usando processamento de linguagem natural avançado e gera uma imagem única do herói.

## Rodando

    python app.py

## Classes

- Guerreiro
- Mago
- Paladino
- Arqueiro
- Ladino

## Dica

Escreva textos bem grandes pra ficar mais forte 😎

## Imagens

Coloque as imagens em `/imagens`.
